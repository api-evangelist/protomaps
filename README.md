# Protomaps

Protomaps is an open-source map system that delivers an interactive map of the world as a single PMTiles file hosted on cloud storage. It provides a hosted vector tile API powered by Cloudflare CDN, plus tools for converting, serving, and delivering map tiles without servers using HTTP range requests.

**Website:** https://protomaps.com  
**Documentation:** https://docs.protomaps.com  
**GitHub:** https://github.com/protomaps  
**Blog:** https://protomaps.com/blog  
**API:** https://protomaps.com/api  

## APIs

- **Protomaps Hosted Tile API** — CDN-backed vector tile API at `api.protomaps.com`
- **PMTiles CLI** — Single-binary tool for PMTiles archive management and self-hosting
- **Basemap Downloads** — Daily OpenStreetMap planet builds in PMTiles format
